# Changes for 9.x

This changelog references the relevant changes (bug and security fixes) done to `orchestra/testbench-browser-kit`.

## 9.2.0

Released: 2024-09-25

### Changes

* Update minimum support for Testbench v9.10.0+. ([v9.5.0...v9.10.0](https://github.com/orchestral/testbench/compare/v9.5.0...v9.10.0))
* Update `laravel/browser-kit-testing` to `^7.2.4`.

## 9.1.0

Released: 2024-09-25

### Changes

* Update minimum support for Testbench v9.5.0+. ([v9.0.0...v9.5.0](https://github.com/orchestral/testbench/compare/v9.0.0...v9.5.0))

## 9.0.0

Released: 2024-13-13

### Changes

* Update support for Laravel Framework v11.
* Use `orchestra/testbench` version `^9.0`.
* Update `laravel/browser-kit-testing` to `^7.2` (compatible with PHPUnit 10.1+ and 11.0+).
